# 첫 비교 실험: 두 조건 모두 통과

실행일: 2026-10-20. **이번 실험에서 스킬의 품질 향상은 입증되지 않았습니다.**

외부 의존성이 없는 작은 Python 주문 예제로, 기존 정책의 재사용과 서로 독립적인
정책 변경을 확인했습니다. 과제당 스킬 사용·미사용 각 1회, 총 4회 실행했습니다.
동일한 모델 설정·도구·초기 코드·요청을 사용했고, 조건별 독립 에이전트가 두 과제를
순서대로 수행했습니다. 서로의 결과와 외부 검사 도구의 정답은 제공하지 않았습니다.

| 과제 | 조건 | 외부 동작 검사 | 결과물 자체 테스트 |
| --- | --- | --- | --- |
| 저장 없는 견적 서비스 추가 | 스킬 사용 | 통과 | 9개 통과 |
| 저장 없는 견적 서비스 추가 | 스킬 미사용 | 통과 | 8개 통과 |
| 기업구매 배송 정책만 변경 | 스킬 사용 | 통과 | 8개 통과 |
| 기업구매 배송 정책만 변경 | 스킬 미사용 | 통과 | 7개 통과 |

두 조건 모두 기존 가격 계산을 재사용했습니다. 기업구매 변경에서는 일반 주문 정책과
입력 오류 동작을 보존했고, 불필요한 공통 배송 프레임워크를 도입하지 않았습니다.
테스트 개수 차이는 확인되지만 그 자체가 품질 우위를 의미하지 않습니다.

외부 검사는 요구사항에서 정한 금액·경계값, 저장 부작용, 기존 가격 함수의 실제 호출,
입력 오류, 기존 주문 동작을 확인했습니다. 변경하지 않은 원본 fixture는 두 과제의
새 요구사항 검사에 모두 실패하여, 구현 없이 통과하는 검사가 아님도 확인했습니다.
작성자가 실제 diff와 추가 테스트를 읽어 검사 약화와 과도한 구조 변경 여부를 검토했습니다.
