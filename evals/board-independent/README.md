# 독립된 사용자 작업 공간의 FastAPI 구현 비교

실행일: 2026-10-21(KST). 이전 README의 before/after는 한 작성자가 만든 설명용
리팩터링이었습니다. 이번에는 **같은 요구를 서로 다른 새 대화와 작업 공간에 제공**해
각각 새 프로젝트를 구현했습니다. 한쪽 결과를 다른 쪽에 넘겨 고치게 한 비교가 아닙니다.

## 분리한 조건

| 항목 | 미사용 | 적용 |
| --- | --- | --- |
| 시작 코드 | 없음 | 없음 |
| 사용자 요구 | 같은 REQUIREMENTS.md | 같은 REQUIREMENTS.md |
| Python 환경 | 별도 .venv | 별도 .venv, 같은 22개 패키지 버전 |
| 작업 위치 | 저장소 밖 독립 폴더 A | 저장소 밖 독립 폴더 B |
| 대화 | 새 Claude Code 프로세스, 이전 대화 없음 | 별도 새 프로세스, 이전 대화 없음 |
| Sharp Frames | 노출·설치 안 됨 | development만 프로젝트 스킬로 설치·직접 호출 |
| 기존 예제·상대 결과·외부 검사 | 제공하지 않음 | 제공하지 않음 |

Claude Code 2.1.292, 세션에서 확인한 모델은 두 조건 모두 `claude-opus-5-5`입니다.
모델은 따로 지정하지 않았습니다. 프로젝트 설정만 사용하고 MCP·Chrome·외부 플러그인을
제외했습니다. 호스트 기본 스킬과 편집·셸·읽기 도구는 양쪽에 동일하게 제공했습니다.
사전 점검 세션은 종료하고 구현은 다시 새 세션에서 시작했습니다.

이 분리는 폴더·대화·설정·가상환경의 분리입니다. 같은 OS 계정·인증 계정·기본 Python과
패키지 캐시를 쓰므로 별도 VM/OS 사용자와 동일한 보안 경계는 아닙니다. 미사용 세션은
자체 서버 종료 문제를 확인하며 OS 프로세스 메타데이터를 조회했습니다. 기록된 파일 접근과
셸 명령에서는 상대 소스·기존 예제·평가 코드를 읽은 흔적이 없었습니다. 이 감사는
악의적인 우회를 막는 파일 시스템 보안 증명은 아닙니다.

## 관측한 구성

두 구현 모두 모듈화와 작성자 정책 재사용을 선택했습니다. 미사용을 한 파일로 만들도록
지시하거나, 적용 쪽에 의도한 폴더 구조·수정 정답을 제공하지 않았습니다.

- 미사용은 `security.py`·`deps.py`·`schemas.py`를 분리하고 `_get_own_post_row`를
  수정·삭제에서 공유합니다.
- 적용은 인증·입력 모델을 기능 모듈에 함께 배치하고 `find_own_post`를 공유합니다.
  요구와 검사 연결을 담은 `tests/CASE_MATRIX.md`도 제출했습니다.
- 두 정책 모두 없는 글 404·다른 작성자 403을 판단합니다. 한쪽만 권한 검사를
  재사용했다는 설명은 이번 결과와 맞지 않습니다.
- 자체 검사 로그는 미사용 29개, 적용 28개의 통과를 기록했습니다. 두 검사 집합은
  서로 다르며 개수는 품질 점수가 아닙니다. 외부의 동일한 9개 그룹을 주 비교로 사용했습니다.

원본 제출물은 [실행 가능한 두 프로젝트](../../examples/fastapi-board-independent/README.md)에
수정 없이 보관했습니다. 폴더 수·줄 수를 개선 점수로 환산하지 않았습니다.

## 실행 근거와 재실행

[증빙 압축 파일](evidence-2026-10-21.zip) · [압축 파일 SHA-256](archive-sha256.txt).
원본 제출물과 지문, 고정된 요구·검사·실행 계획, 평가 스킬, 실제 스킬 노출 메타데이터,
편집·셸 명령, 셸 실행 결과, 최종 응답과 시간·토큰 정보를 보관했습니다.
관측 로그와 준비 스크립트의 개인 경로는 자리표시자로 바꾸고 thinking은 포함하지 않았습니다.
제출 코드와 고정 검사 본문은 원래 바이트로 보관했습니다.

실행 당시 작업 폴더와 원시 JSONL은 로컬에 남겨 두었습니다. 버전 관리 자료에는
가상환경·실행 DB·캐시를 넣지 않았습니다. 생성 시간은 미사용 281.66초, 적용 362.37초였으나,
동시 실행·캐시·자체 검사량이 달라 개발 속도나 비용의 우열로 해석하지 않습니다.
CLI의 API 환산 비용 메타데이터도 실제 계정 청구액을 뜻하지 않습니다.

저장된 코드와 결과만 다시 검사하는 명령입니다. AI를 새로 실행하거나 제출물을 수리하지 않습니다.

```sh
python -m pip install -r examples/fastapi-board-independent/with-skill/requirements.txt
python -X utf8 evals/board-independent/replay.py
```

초기 환경 점검에서 restricted 모드가 프로젝트 스킬 발견을 막는 것을 확인해 **구현 시작 전**
양쪽 모두 해당 옵션을 제외했습니다. 외부 검사 사전 점검의 Windows 서버 로그 파일 정리
오류도 구현 시작 전에 수정했습니다. 입력 지문은 준비 코드에서 LF 텍스트로 계산한 뒤
Windows가 CRLF로 저장했으므로, 텍스트 지문은 LF 정규화로 확인하고 두 입력 파일의
실제 바이트 지문도 서로 같음을 별도로 확인했습니다. 이를 입력 변경으로 세지 않았습니다.
이 설정 점검·초기 오류 기록도 증빙에 포함했습니다.

조건별 1회·단일 합성 과제이며 독립된 여러 사용자·모델·프로젝트에서 반복한 연구는 아닙니다.
비대화형 CLI에서 도구를 미리 허용했으므로 실제 사용자의 승인 UX·브라우저·온보딩을
평가하지 않았습니다. 운영 보안·동시성 전체·성능·사람의 유지보수 시간은 미측정입니다.
