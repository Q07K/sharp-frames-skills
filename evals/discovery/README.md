# 기능 탐색·계획·버전 검토의 수용 검사

실행일: 2026-10-20. 신규 세 스킬을 작은 합성 저장소에 명시적으로 적용한 독립 에이전트
실행입니다. 스킬 사용·미사용 비교나 생산성 벤치마크가 아닙니다. 입력 코드와 요청,
적용할 스킬 경로만 제공하고 정답·이전 보고서는 제공하지 않았습니다.

| 사례 | 확인 대상 |
| --- | --- |
| 재주문 방식 탐색 | 사용자 확인 조건, 기존 계산·권한 모듈, 대안·최소 범위·수용 기준, 임의 정책과 기존 사실 구분 |
| 재주문 미리보기 계획 | 실제 함수 활용, 호출·권한 검사 순서, 현재 가격·품절 보존·원본 불변, 단계와 검증의 구체성 |
| Pydantic 버전 검토 | 실제 코드와 공식 변경·호환 문서, 개발자 경험, 유지·이전 비교, 필수 수정·선택 활용·검증 구분 |
| 오프라인 버전 검토 | 로컬에서 아는 사실과 추가 조사 필요 항목 구분, 최신성·보안·지원 상태를 추측하지 않음 |

작성자가 실제 네 응답·추적 기록을 읽고 위 범위의 동작을 확인했습니다. 전체 입력 파일의
집합과 SHA-256은 네 사례 모두 유지됐습니다. 온라인 사례의 주요 공식 자료와 이슈 링크도
별도로 확인했습니다. 탐색·계획 에이전트는 WindowsApps Python을 시작하지 못했고 이를
통과로 보고하지 않았습니다. 작성자가 사용 가능한 Python으로 원본 fixture의 기존 검사
1개를 실행해 통과했지만, 이는 새 기능 구현이나 계획의 모든 검증을 실행한 결과가 아닙니다.
버전 후보의 설치·실행·배포는 수행하지 않았습니다.

입력은 운영 서비스가 아닙니다. 온라인 사례의 버전 조사 결과는 해당 실행 시점의 기록이며
다른 프로젝트에 대한 현재 권고나 최신 버전 데이터베이스로 사용하면 안 됩니다.
반복 사용할 때는 각 프로젝트와 당시 공식 자료를 다시 확인해야 합니다.

실행의 응답·추적 자료와 작성자의 독립 검사 결과는 [관측 결과](checks.json),
[입력·요청](cases.json), [원본 자료 압축 파일](forward-evidence.zip),
[압축 파일 해시](archive-sha256.txt), [스킬 지문](skill-files-sha256.json)에 있습니다.
스킬 지문은 UTF-8 텍스트의 줄바꿈을 LF로 통일한 기준입니다. 압축 파일의 개인 경로는
표시용 자리표시자로 바꾸고 `.git`·임시 캐시는 제외했습니다.

형식·로컬 링크·명령 목록 일치는 패키지 검사로 별도 확인합니다. CI는 저장된 기존 API
평가를 재실행하지만 이 인터넷 조사나 새 에이전트 실행을 매번 반복하지 않습니다.
실제 호스트 자동 선택, 큰 저장소 전반, 다른 생태계의 이전 성공은 확인하지 않았습니다.
시간·토큰·사람의 검토 시간·운영 성능 효과는 측정하지 않았습니다.

이 검사는 기능의 기본 수용 범위를 확인합니다. 작은 예제에서의 성공으로 품질 우위나
한 번에 올바른 코드를 생성하는 보장을 주장하지 않습니다.
